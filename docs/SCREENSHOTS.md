# Screenshot provenance

The images in `assets/screenshots/` come from the `browser-e2e` job of [GitHub Actions run 35446357041](https://github.com/OthmaneBlial/AetherTerm/actions/runs/35446357041), on commit `dbaf5e9`. The complete run passed its Python, Web asset, real Chromium and non-root container jobs on Ubuntu 24.04. The screenshots were generated by `scripts/verify_browser.py`, downloaded from the run's `chromium-screenshots` artifact, visually inspected and copied byte-for-byte into this repository.

| `mobile.png` | 375 × 1063 | `917a140210e017a9d8c32c97dc097508ef443e08689c61c18ac1d2923da8dd99` |

The script installed the current Python package, started a loopback server and real agent with disposable credentials, signed in through Chromium, opened a PTY, restarted the server, signed in again, and ran `cd /tmp`, `printf 'Live shell connected\n'` and `uname -s` in the second shell. It captured the desktop and 375 px layouts before running further interrupt and Unicode-output checks. No interface or terminal output was mocked. The pictured `browser-agent` and runner hostname belong to the temporary CI environment, not a user deployment. The images show this prototype commit; they do not prove remote TLS, a release download, a touch device or production readiness.
